# Support

Astron is the AIC 2026 competition identity evolved from the public PAIOS CE
baseline. Here is where to get help and how to route different kinds of questions.

## Bugs and defects

If you hit a reproducible defect, open an issue using the
[Bug report](https://github.com/chengcheng-2006/paios-ce/issues/new/choose)
form. Include a minimal reproduction with placeholders only — never real
secrets, tokens, personal data, or private paths.

## Security issues

Do **not** open a public issue for vulnerabilities. Follow the reporting
process in [SECURITY.md](SECURITY.md).

## Feature ideas

Suggest features through the Feature Request form so the problem, proposed
behavior, and security implications are captured.

## Usage questions

For usage questions that are reproducible as documentation or behavior
problems, open an issue using the closest available form. Before asking,
check:

- the [README](https://github.com/chengcheng-2006/paios-ce#readme);
- [docs/FAQ.md](docs/FAQ.md);
- [SUPPORT_MATRIX.md](SUPPORT_MATRIX.md) — what the current release candidate
  does and does not support.

## Scope of this candidate

Live integrations (real providers, channels, cloud services, browser or shell
workers) are not part of the current release candidate. Questions about them
belong in roadmap discussion, not support requests.
