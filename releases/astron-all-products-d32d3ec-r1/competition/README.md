# 竞赛材料与离线演示

此目录收纳此前生成的定位、技术报告、问答、证据基线、演示说明和静态前端，供评审与复核使用。

## 版本与证据边界

- 产品源码副本位于 `../source/`，源快照为 `d32d3ec1bc49a78d0b14aabb6bf0daf79d3f4d88`，树为 `c6953180dcd732c425e77b0acd004321a39837ac`。
- 本目录的竞争材料基于较早的证据基线 `11c6114f6ec0504628f912ebde9ba53821badb03` / 树 `2d0e6477c7d4e083bbd23e44a7228b7eedb47e24`。这些材料**不证明**后来的 `d32d3ec` 快照通过了相同的真实模型运行或测试。
- `11c6114` 的证据基线记录一项受控仓库任务和独立故障证据；产品包的 `RELEASE_MANIFEST.json` 记录的 R2 评测运行则属于 `13ee283`。这是两条不同的证据线，不能彼此替代或合并。`d32d3ec` 没有自己的正式模型实跑证据。
- 证据基线的本机绝对路径已在公开副本中脱敏；证据包本体未纳入 GitHub 上传，所以其中的摘要值仍是报告所记载的值，本次上传没有对原始运行证据进行重新哈希核验。
- 四个 HTML 页面是使用本地回放 JSON 的静态离线演示，不连接 Astron 运行时。页面页脚标明了基线版本。

## 文件索引

- `docs/`：定位、README 首屏草稿、技术报告、分镜、视频脚本、评委问答与主张语言边界。
- `showcase/`：四份评委简介、演示稿、PPT 提纲与问答；文字已标明 d32 / 13ee 版本边界。
- `evidence/ASTRON_COMPETITION_EVIDENCE_BASELINE_V1.md`：历史证据基线的公开脱敏副本。
- `demo_evidence/`：六份演示证据与屏幕映射材料。
- `visual/`：四个场景页、首页、CSS/JavaScript、本地回放数据和视觉审查说明。先打开 `visual/index.html`。

## 本机预览

进入本目录的 `visual/` 后，可直接打开 `index.html`。若浏览器限制本地 JSON 读取，可在该目录运行 `python3 -m http.server 8000`，再访问 `http://127.0.0.1:8000/`。此预览仍是离线静态回放，不代表启动或验证产品运行时。
